# 印页 · Inkleaf 0.5.0

这一版集中改进排版、预览与设置体验，并加入独立开发模式。

## 更新内容

- **Folio（开本）成为新的默认 PDF 主题。** 保留 Classic 和 Minimal，已有用户保存的主题选择不覆盖。旧 Dark PDF 主题已移除。
- **App 浅色、深色与跟随系统。** 在 General 中切换，立即生效、自动保存；界面外观不影响 PDF 的配色与排版。
- **重新设计设置界面。** 分类与内容分组更清晰，排版预览更大并支持缩放；排版修改需明确保存，离开未保存的页面时会提醒。
- **更完整的高级排版。** 调整 H1–H6 的字号、颜色和间距；控制标题、表格、代码块及章节分页；自定义页眉页脚、页码格式、位置和署名版权。
- **直接查看修改效果。** 页眉、页脚和版权可定位并高亮，位置选项自动定位；分页规则提供示例对比，模板补齐六级标题与不同语言的代码。
- **更清晰的代码高亮。** 按语言和语法区分颜色，所需资源随安装包提供。
- **修复窗口与导航交互。** 搜索栏对称调整宽高，设置分类切换不再向右偏移；预览及加载期间均可按 Esc 返回搜索。
- **独立的 Inkleaf Dev。** 开发版和正式版分别保存设置、索引与缓存，使用不同默认快捷键，可同时运行；开发版不检查正式版更新。
- **统一用户数据目录。** 正式版使用 `%APPDATA%\Inkleaf`；首次启动时，如目标尚无设置，将复制旧 Aldus 设置，旧目录保持不变，索引重新建立。
- **更新双语文档与演示。** 新增开发命令速查与使用许可说明。

## 安装与更新

仅提供 Windows x64 安装包。首次使用下载 `Inkleaf-Setup-0.5.0.exe`；已安装 0.4.11 的用户可在应用内检查更新、下载，再选择“重启并更新”。`.blockmap` 和 `latest.yml` 是更新器使用的文件，手动安装无需单独下载。

默认快捷键：正式版 **Ctrl + Shift + Space**；开发版 **Ctrl + Alt + Shift + Space**。个人非商业使用免费；商业使用需事先获得 Alex Tian 的书面授权，费用另议，作者本人及其控制的公司按 LICENSE 中的例外条款使用。本版本随附完整许可，不是 MIT 许可。

## What's new

- **Folio is the new default PDF theme**, alongside Classic and Minimal. Existing saved theme choices are preserved. The old Dark PDF theme has been removed.
- **Light, Dark and System app appearance**, available in General, saved automatically and independent of PDF styling.
- **Redesigned settings**, with clearer groups, a larger zoomable layout preview, explicit layout saving and unsaved-change prompts.
- **Advanced typography and pagination:** H1–H6 styles, heading/table/code pagination rules, chapter breaks, custom headers and footers, page numbers and copyright placement.
- **Visible layout feedback:** jump to and highlight affected areas, compare pagination rules, and preview a sample with all six heading levels and language-labeled code.
- **Language-aware code highlighting** using bundled resources.
- **Window and navigation fixes:** symmetric search-bar resizing, stable settings positions, and Esc to return to search even while a preview is loading.
- **Isolated Inkleaf Dev**, with separate preferences, indexes, caches and shortcuts. Development builds do not install production updates.
- **Inkleaf user-data directory**, with first-run copying of legacy Aldus settings when no Inkleaf settings exist. The original directory is retained and indexes are rebuilt.
- **Updated bilingual documentation and demos**, a command reference and license information.
