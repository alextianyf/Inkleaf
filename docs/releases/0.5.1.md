# 印页 · Inkleaf 0.5.1

## 本次更新

- **恢复 Classic 为默认 PDF 主题。** 当前仅保留 Classic 和 Minimal，Folio 暂时下架。已有 Folio 设置会自动回退到 Classic，其他偏好保留；已选择 Minimal 的用户保持原样。
- **保留原有标题与编号。** 不再由主题自动添加章节号，避免与文档已有编号重复。开发期间尝试的标题编号、智能编号和重新编号功能暂不提供，相关设想移入后续计划。
- **单击搜索结果即可预览。** 文件打开 PDF 预览，文件夹打开批量预览；继续支持 Enter 打开、Esc 返回，包括预览加载期间。
- **修复多行标题跨页分离。** 能放入单页的完整标题保持同页；“标题与后文同页”单独控制后文是否跟随。

这些调整不改写原 Markdown 文件。后续优先优化 Classic，暂不开发新主题；未来新增主题也将以 Classic 为基础。

## 下载与更新

Windows x64 用户下载下方 **Inkleaf-Setup-0.5.1.exe** 安装。已安装的用户可在设置的“关于与更新”中检查更新，点击下载，完成后选择“重启并更新”。`.exe.blockmap` 和 `latest.yml` 供应用内更新使用，无需手动打开。

## What's changed

- **Classic is the default PDF theme again.** Classic and Minimal remain available; Folio has been withdrawn. Saved Folio preferences fall back to Classic while other settings are preserved. Existing Minimal selections stay unchanged.
- **Authored headings and numbers are preserved.** Themes no longer add chapter numbers that could duplicate existing numbering. The heading-numbering experiments remain on the roadmap and are not available in this release.
- **Single-click a search result to preview.** Files open PDF previews and folders open batch previews. Enter and Escape remain supported, including cancellation while loading a preview.
- **Keep multiline headings together.** A complete heading stays on one page when it fits. Keeping the following text with it remains a separate layout setting.

Original Markdown files stay unchanged. Future design work will focus on Classic; any new themes should build on it.
