# 印页 · Inkleaf 0.6.1

## 本次更新

- **修复项目内共享图片无法显示。** 多层课件可以引用最近 Git 项目内的共享 Logo、图片和 SVG badge，包括 worktree 项目。项目外本地路径仍被拦截；不在 Git 项目内的文档，以所在文件夹为边界。
- **渲染问题不再容易漏看。** 单文件和文件夹预览出现缺图、布局限制或未修复语法问题时，在 PDF 上方显示提醒。点击“查看详情”查看原因和引用；关闭提醒后，底部详情仍保留。
- **区分不同的图片问题。** 项目外路径、文件不存在、访问权限、格式不支持、超时、图片过大、损坏无法解码及图片数量上限，都会提供对应说明。
- **失败和成功分别说明。** 预览、导出失败使用明显的错误卡片。导出成功不会自动隐藏内容警告，避免将“文件保存成功”误认为“所有内容均已完整渲染”。成功自动修复的 Markdown 语法仍以普通提示呈现。
- **Modern 内置中文黑体。** 标题、正文、表格、代码注释和署名使用 Noto Sans SC；英文继续使用 Inter，代码使用 JetBrains Mono。字体按文档所需字符选择离线切片，全部切片约 4.3 MiB，无需在转换时下载字体。Classic、Minimal 保留原有字体设置。

转换不修改 Markdown 源文件。打印页眉页脚和内置字体未覆盖的字符仍使用系统字体。

## What's changed

- **Shared project images render correctly.** Nested lessons can reference shared logos, images and SVG badges within the nearest Git project, including worktrees. Local references outside that boundary remain blocked. Standalone documents use their containing folder as the boundary.
- **Visible rendering notices.** Single-file and folder previews display a notification over the PDF for missing images, layout limitations and unresolved source diagnostics. **View details** opens the reasons and references; dismissing the notification keeps the details available below the preview.
- **Actionable image failures.** Notices distinguish blocked paths, missing files, permissions, unsupported formats, timeouts, oversized images, decoding failures and the image-count limit.
- **Clear failure feedback.** Preview and export failures show an error card. Saving a PDF does not dismiss content warnings: a successful save does not guarantee every resource rendered. Successfully repaired Markdown syntax remains informational.
- **Bundled Chinese sans-serif for Modern.** Noto Sans SC covers document headings, body text, tables, code annotations and signatures. Inter remains first for Latin text, and JetBrains Mono for code. The offline font subsets total about 4.3 MiB; only the subsets needed by each document are embedded. Classic and Minimal retain their font choices.

Source Markdown files remain unchanged. Printed page headers/footers and characters outside the bundled repertoire still use system fonts.
