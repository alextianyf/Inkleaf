# 印页 · Inkleaf 0.6.0

## 本次更新

- **Modern 成为默认 PDF 主题。** 新安装、没有有效主题偏好及恢复排版默认时使用 Modern；已有用户选择的 Classic 或 Minimal 保留。三套主题都可以在设置中切换。
- **更清晰的讲义排版。** Modern 内置 Inter 与 JetBrains Mono 英文字体，提供六级标题层次、黄色引用、红色行内代码、表格、图片与图注样式。中文使用系统字体回退。
- **Modern 代码卡片。** 显示语言标签，五行及以上自动显示行号；代码围栏语言后可加 `numbers` 或 `nonumbers` 控制。Classic 与 Minimal 沿用原有代码呈现。
- **支持五种 Markdown 标注块。** `> [!NOTE]`、`TIP`、`IMPORTANT`、`WARNING`、`CAUTION` 在所有主题中可用，标签支持中英文。
- **预览进度更直观。** 显示读取、排版、生成 PDF、显示页面四步进度，最后一步依据实际显示页数推进；这是流程进度，不是剩余时间估计。
- **导出成功更明确。** 保存后在 PDF 预览上方悬浮提示成功和文件名，底部保存路径保留。取消或失败不会显示成功，批量任务全部完成时也会提示。
- **建立可重复的质量检查。** 完整样本覆盖标题、强调、列表、引用、代码、公式、表格、图片、HTML、脚注及跨页；开发命令 `check:quality` 检查三主题及中英文标签，`check:grayscale` 提供灰度页面和文字对比度基准检查。人工审阅仍是发布检查的一部分。

转换不改写原 Markdown。保留 Modern、Classic、Minimal，清理废弃主题与设计对照产物。

## What's changed

- **Modern is now the default PDF theme** for new profiles, missing/invalid theme preferences and layout resets. Existing Classic and Minimal choices are preserved. All three themes remain available.
- **A new handout layout**, with bundled Inter and JetBrains Mono Latin fonts, six heading levels, yellow quotations, red inline code, tables, images and captions. Chinese text uses system font fallbacks.
- **Modern code cards** show language labels and number blocks of five or more lines. Add `numbers` or `nonumbers` after the fence language to override this behavior. Classic and Minimal retain their original code rendering.
- **Five Markdown callouts:** `> [!NOTE]`, `TIP`, `IMPORTANT`, `WARNING` and `CAUTION`, with English and Chinese labels across all themes.
- **Preview progress** shows actual reading, layout, PDF generation and page-display stages, including rendered page counts. It is workflow progress, not a time estimate.
- **Clear export confirmation:** a dismissible message floats over the PDF after a successful save, while the saved path stays available. Cancelled or failed saves never report success; fully successful batches also show confirmation.
- **Reusable quality checks** cover the supported Markdown/HTML feature set across themes and languages, with PDF text/resource checks, page images, grayscale views and baseline text contrast checks. Visual review remains necessary.

Source Markdown files remain unchanged. Modern, Classic and Minimal are retained; obsolete theme-review artifacts have been removed.
